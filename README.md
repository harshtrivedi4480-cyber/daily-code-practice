# 🔥 Daily Code Practice

> Solving a new challenge every day and committing it here. **Consistency > Perfection.**

This repository is my personal daily DSA and coding practice log. Every problem here is solved and typed out by me — this is my own learning journey, tracked one day at a time.

---

## 📌 How It Works

1. 🎯 Pick a new problem/task every day (DSA, mini project, or concept practice)
2. 📁 Create a `dayXXX-topic-name/` folder inside `solutions/`
3. 💻 Write the code myself, test it thoroughly
4. 📝 Update the Progress Tracker table below
5. 🚀 Commit + push to GitHub

## 🗂️ Folder Structure

\```
solutions/
  day001-topic-name/
    solution.cpp / .js / .py
    notes.md   (dry-run, approach, complexity analysis)
\```

Inside each day's folder:
- **solution.[ext]** → actual code
- **notes.md** → approach, dry-run table, time/space complexity
